# 🍕 Pizza Sales SQL Analysis Project

## 📌 Project Overview
This project analyzes pizza sales data using SQL to generate business insights related to:
- Sales Performance
- Revenue Trends
- Customer Ordering Patterns
- Product Performance

---

# 🗂️ Dataset Information

The dataset contains 4 tables:

| Table Name | Description |
|------------|-------------|
| orders | Stores order date and time |
| order_details | Stores quantity and pizza ordered |
| pizzas | Stores pizza size and price |
| pizza_types | Stores pizza names and categories |

---

# 📊 Analysis Performed

## 1️⃣ Basic Order Analysis
- Total Number of Orders
- Orders Distribution by Hour
- Average Pizzas Ordered Per Day

## 2️⃣ Revenue Analysis
- Total Revenue Generated
- Revenue Contribution by Category
- Cumulative Revenue Trend

## 3️⃣ Pizza Performance Analysis
- Highest Priced Pizza
- Most Common Pizza Size
- Top 5 Most Ordered Pizzas
- Top 3 Revenue Generating Pizzas

## 4️⃣ Category Analysis
- Quantity Ordered by Category
- Category-wise Pizza Distribution
- Top Revenue Pizza in Each Category

---

# 🛠️ Tools Used
- SQL
- MySQL

---

# 📈 Key Insights
- Large pizzas were ordered the most
- Certain pizza categories generated higher revenue
- Peak ordering hours were identified
- Revenue growth trend analyzed over time
